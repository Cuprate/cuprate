# cuprated 0.1.0-preview Kesterite (2026-08-01)
Cuprate is a modular Monero node written in Rust. To get started, see: <https://user.cuprate.org>.

**This is a preview release for beta. It includes initial wallet support.**

This release contains updates to our RPC interface to allow wallets to connect to Cuprate. Wallets can now sync the blockchain
and send transactions with Cuprate.

## Changes
- Initial wallet RPC support ([#624](https://github.com/Cuprate/cuprate/pull/624), [#631](https://github.com/Cuprate/cuprate/pull/631), [#634](https://github.com/Cuprate/cuprate/pull/634), [#636](https://github.com/Cuprate/cuprate/pull/636), [#637](https://github.com/Cuprate/cuprate/pull/637), [#641](https://github.com/Cuprate/cuprate/pull/641), [#647](https://github.com/Cuprate/cuprate/pull/647), [#653](https://github.com/Cuprate/cuprate/pull/653), [#654](https://github.com/Cuprate/cuprate/pull/654))
- Add offline mode ([#656](https://github.com/Cuprate/cuprate/pull/656))
- Add graceful shutdown ([#585](https://github.com/Cuprate/cuprate/pull/585))
- Add embeddable `Node::launch()` library ([#592](https://github.com/Cuprate/cuprate/pull/592))
- Add regtest and fakechain support ([#607](https://github.com/Cuprate/cuprate/pull/607))
- Improve Tor networking ([#640](https://github.com/Cuprate/cuprate/pull/640))
- Support SOCKS5 proxy URLs ([#596](https://github.com/Cuprate/cuprate/pull/596))
- Add custom allocator options ([#658](https://github.com/Cuprate/cuprate/pull/658))
- Add Docker, Alpine, FreeBSD, and OpenBSD support ([#659](https://github.com/Cuprate/cuprate/pull/659))
- Respect `NO_COLOR` and non-interactive terminals ([#618](https://github.com/Cuprate/cuprate/pull/618))
- Fix the `--network` argument ([#649](https://github.com/Cuprate/cuprate/pull/649))
- Remove RPC payment support ([#646](https://github.com/Cuprate/cuprate/pull/646))
